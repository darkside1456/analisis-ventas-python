# Análisis de ventas con Python

Proyecto de análisis de datos que procesa un archivo de ventas y genera resúmenes y gráficos automáticamente.

## Herramientas utilizadas

- Python
- pandas
- matplotlib
- CSV

## Análisis realizados

- Ventas totales por ciudad
- Ventas totales por producto
- Ventas totales por categoría
- Panel de gráficos automático
